# Alpha Crush — Realism Pass (2.1.0): asset pipeline

The 2.0 game built everything from boxes and capsules in code. 2.1.0 replaces that with a **procedural art pipeline**
(`tools/assetgen/`) plus a runtime layer (`visuals/`) that loads the generated assets, so the whole world, the
human avatar, the animals, the sky and the soundscape are rebuilt around physically-based materials.

> **Honest scope.** Everything is generated by code (numpy / scikit-image / PIL) — there is no hand-sculpted or
> scanned content. The result is a coherent *stylised-realistic* look (PBR materials, proportioned characters,
> real lighting) rather than photographic realism. `docs/previews/` shows offline software renders of the
> generated assets; they are **not** engine screenshots (no Godot runtime was available when this was built).

## What is generated

| Output | Generator | Contents |
|---|---|---|
| `assets/textures/` (44 files) | `build_textures.py` | seamless PBR sets (albedo JPG, tangent-space normal JPG, ORM PNG): grass, dirt, rock, sand, cobble, wood planks, bark, plaster, brick, roof tiles, awning, cloth, iron; leaf / grass-tuft / flower alpha atlases; water + micro-detail normals |
| `assets/models/` (56 GLB, ~6 MB) | `build_models.py` | male + female human (rigged joint hierarchy, face, hair, clothing masks), backpack + 3 hats, 8 trees, 2 bushes, 4 rocks, cottage, market hall, workshop, community hall, storage hut, lighthouse beacon, garden bed, docks, bridges (sound + broken), boats (sound + damaged), gates, cave mouth, ladder, scarecrow, lamp post, signpost, fence, bench, well, haystack, wheat, fruit / wood / stone / ore resources, letter gem, cow, goat, deer, chicken, distant mountain ring |
| `audio/ambience/`, `audio/sfx/footstep_grass_*` | `build_audio.py` | seamless day / night / river / rain beds (FFT-shaped circular noise + synthesised birds and crickets) and grass footsteps |
| `docs/previews/` | `preview_scene.py` + `preview.py` | offline composition renders used to check orientation, scale and proportions |

Regenerate everything with:

```bash
python3 tools/assetgen/build_textures.py [--scale 1.0]     # 0.5 for smaller textures, 1.5 for larger
python3 tools/assetgen/build_models.py [model_name ...]
python3 tools/assetgen/build_audio.py
python3 tests/asset_audit.py                                # validates every GLB / texture / shader / marker name
```

Requires `numpy`, `scipy`, `scikit-image`, `Pillow` (no Blender, no network).

## Runtime layer (`visuals/` and `world/village_art.gd`)

* `MaterialLibrary` — model material *names* → PBR `StandardMaterial3D`s / shader materials (terrain, water, foliage, grass, avatar, sky).
* `PropFactory` — loads a GLB, applies the materials, turns `COL_BOX_w_h_d` / `COL_CYL_r_h_0` / `COL_SPH_r_squash_0`
  marker nodes (centimetres; Godot strips `.` from node names) into static collision.
* `TerrainField` — one height function for everything: flat authored village, carved river bed and ravine, rolling hills beyond.
  Triangles are wound clockwise-from-above (Godot's front face) so the ground is visible and solid.
* `Atmosphere` — procedural sky shader (sun disc, cumulus, stars), continuous sun/moon arc from the world clock,
  weather (cloud cover, fog, rain particles), filmic tone-mapping, distant mountains, window / lamp glow at night.
  SSAO/SSIL switch on automatically under the Forward+ renderer.
* `Vegetation` — region profiles → MultiMesh trees/bushes/rocks per streamed chunk, plus grass tufts and flower clusters near the player.
* `AvatarRig` — loads the human model and animates it procedurally (idle breathing, walk/run cycle, jump pose, carrying pose, interact reach).
* `VillageArt` — builds each landmark from models while keeping every node name the story code looks up.

Everything degrades gracefully: if a model, texture or shader cannot be loaded the game falls back to the 2.0 placeholders.

## Budgets and quality tiers

Human ≈ 22k triangles (Godot generates LODs on import), trees ≈ 1.3–2k, buildings 2–10k, animals 3–5k.
`QualityManager` scales shadows, stream radius, grass density and prop density per tier (low … ultra).
The project renders with **GL Compatibility** (broadest Android support). For a richer desktop look set
`renderer/rendering_method="forward_plus"` in `project.godot`.

## Swapping in your own art

* Replace any `assets/models/<id>.glb` with a model that uses the same material slot names (see `matdefs.py`).
* The avatar expects joints named `Hips, Spine, Neck, Head, UpperArm_R/L, Forearm_R/L, Hand_R/L, Thigh_R/L, Shin_R/L, Foot_R/L`
  and attachment nodes `Attach_Back`, `Attach_Hat` (rigid segments; a skinned character would need a different animator).
* Edit textures by changing the recipes in `texgen.py`, or drop in photographic PBR sets under the same file names.
